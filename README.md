# Earth Pulse

**Seismic event / time window / aggregation.**

A standalone GeoGeek Observatory instrument for reading the current USGS earthquake field while keeping event time, magnitude, depth, filtering, and aggregation distinct.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deployment

GitHub Pages deploys automatically from `main` through `.github/workflows/pages.yml`.

Public URL: https://geogeeklab.github.io/earth-pulse/
